# NakedOnline

XORD NakedOnline — Browser Privacy Exposure Scanner

See exactly what websites can extract from your browser fingerprint.

---

## What It Scans

Basic Mode:
- Public IP, geolocation, ISP
- User agent, platform, language, timezone
- Screen resolution, CPU cores, device memory
- Canvas fingerprint
- WebGL vendor/renderer
- Audio fingerprint
- Fonts, storage capabilities

Deep Naked Mode:
- All of the above, plus:
- WebRTC IP leak detection
- Speech synthesis voices
- Media devices (cameras/mics)
- Battery status
- Motion sensors
- Timing analysis
